# Bold game prototypes

Three small, separate game ideas built around the random "pick 1 of 3 buildings" choice
(Sébastien, 2026-11-24). Each one is a single self-contained `index.html` (no build step).
They don't touch the main game or the Frontier preview.

| Folder | Idea | Preview |
| --- | --- | --- |
| `model-island/` | Model Railway Island: tile puzzle, pick 1 of 3 pieces, score good neighbours, 26-piece runs | https://claude.ai/artifact/J1G32vX1yHmufv2U5ubLNh |
| `long-train/` | The Long Train: one train's journey to Port Haven, pick forks and 1 of 3 wagons at towns | https://claude.ai/artifact/AU8bvtRTiDQ1Yh7Msns2Qr |
| `station-town/` | Station Town: one station grows a city, build platforms, pick 1 of 3 buildings as it grows | https://claude.ai/artifact/TvJUngqPqowQyGD61b9Yk2 |

Open a file directly in a browser to play. Each keeps its own save in localStorage.
