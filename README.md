# Railhaven

Build a railway across an endless archipelago. A mobile-browser game by Sébastien.

- Play the current game: the live link in the project.
- `npm install`, then `npm run dev` to run the rebuild locally (`npm run dev -- --host` to open it on your phone).
- `npm test` runs the checks. `npm run build` makes one self-contained `dist/index.html`.

See `CLAUDE.md` for design rules and `docs/PARITY.md` for rebuild progress.
